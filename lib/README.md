# DNS Security Ontology (DSecO) -- third party dev tools

This folder allows for the local storage of development tools, as needed by each developer.
It is recommended not to commit/push the tools in this folder to GitLab, unless it is a specific version of a tool that would not be available otherwise.

Tool examples:

- Jena SPARQL : http://richard.cyganiak.de/blog/wp-content/uploads/2013/09/jena-sparql-cli-v1.pdf
- lambdamusic/ontopsy : https://github.com/lambdamusic/ontospy
- ontodev/robot : http://robot.obolibrary.org/
- Widoco : https://dgarijo.github.io/Widoco/
